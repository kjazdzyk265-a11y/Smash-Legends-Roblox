# Smash Legends Roblox

A forward-progression destruction simulator for Roblox.

Core loop: train Strength -> smash objects -> earn Coins -> buy stronger tools -> hatch pets -> break zone gates -> progress forward.

## V1 world direction
The world is intentionally a compact forward expedition, not a flat open baseplate.

1. Greenyard — bright starter valley, blacksmith, training yard, crates/barrels/fences/rocks, starter egg, giant wooden gate.
2. Construction City — denser industrial street with cars, concrete, dumpsters and armored truck landmark.
3. Crystal Caves — vertical glowing cave with crystal clusters, geodes and giant crystal boss.
4. Magma Forge — volcanic forge, chains, anvils, obsidian and forge core.
5. Void Temple — dark magical endgame route culminating in the Void Monolith.

Each zone should preview the next zone from its exit. Main route is obvious, with short side pockets for egg/training/rare breakable/secret. No long empty walks.

## Rojo
Run `rojo serve` from this repository and connect with the Roblox Studio Rojo plugin.

Important: imported art should eventually use a Studio-safe asset workflow that Rojo does not own/delete. Do not map a Studio-imported Art folder until preservation semantics have been verified in Studio.
